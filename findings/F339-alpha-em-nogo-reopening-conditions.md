## 4. Independent re-verification (this finding's own checks, not a restatement of the cited findings)

Rather than cite F251's and F279's numbers, `test_F339_alpha_em_reopening_conditions.py` recomputes the two load-bearing algebraic facts from scratch:

- **`test_ward_transversality_exact`** — confirms symbolically (sympy, four generic real $q^\mu$, Minkowski $\eta=\text{diag}(1,-1,-1,-1)$) that *once* $\Pi^{\mu\nu}$ is assumed to take the transverse form $\Pi(q^2)(q^2\eta^{\mu\nu}-q^\mu q^\nu)$, $q_\mu\Pi^{\mu\nu}=0$ follows identically. **This is a model-independent tensor-algebra tautology, true for any scalar $\Pi(q^2)$ whatsoever — it does not re-derive the harder, model-specific fact F251/F277 establish: that the model's actual one-loop fermion bubble (Dirac trace + BZ angular average) takes that transverse form in the first place.** That computation is credited to F251/F277 alone and is not repeated here; this check only makes explicit, rather than silently assume, the trivial corollary their own code already isolates (`ward_identity_symbolic`). Avenue A's narrowing in §3 rests entirely on F251/F277, not on this check.
- **`test_hypercharge_rank_one_free_direction`** — builds F279's six-row system (2 anomaly rows + 3 Yukawa mass-step rows + the Majorana row $2y_\nu=0$) as a $6\times7$ rational matrix and confirms $\text{rank}=6$ (sympy `Matrix.rank()`, exact over $\mathbb Q$), i.e. nullspace dimension exactly 1. This is the fact avenue D's reopening condition rests on.
- **`test_mu_star_is_4pi_v_not_a_lattice_scale`** — recomputes $4\pi v$ from $v=(\sqrt2\,G_F)^{-1/2}=246.22$ GeV and confirms it lands within F138's own quoted 10% scale-matching band of the Higgs-free running crossing point $\mu_\times=3.42$ TeV (not the bare-SM 3.7 TeV F127 quoted), and separately confirms $\mu_\star/E_\text{lat}$ is still $\sim10^{-15}$ regardless — i.e., structural origin and "no lattice-scale coincidence" are both simultaneously true, which is exactly avenue B's resolution in §3.
- **`test_log_ratio_coincidence_is_tautological`** — a documented negative micro-result. While drafting this finding, the ratio $\mu_\star/E_\text{lat}\approx e^{-33.85}$ was momentarily flagged as a possible "34 e-foldings" RG-hierarchy hint (a mechanism that *would* be a legitimate fifth avenue, paralleling how $\Lambda_\text{QCD}$ arises from dimensional transmutation elsewhere in the model). It is not: for **any** ratio $r$, $r\equiv e^{-\ln(1/r)}$ identically, so "the log of the ratio is some number" carries zero independent information unless that number is reproduced by an *unrelated* calculation (an actual beta-function integration with an independently-motivated starting coupling and scale). No such independent calculation exists. This check asserts the identity for several unrelated ratios to make the vacuousness mechanically explicit, specifically so a future session does not spend time on this exact dead end — the D#14 prompt's own warning about this field's history of false positives is the reason to record a rejected idea, not just accept ones.

4/4 PASS. Results: `test-results/F339_alpha_em_reopening_conditions.json`.

Both are legitimate next-session claims. Neither is started here, consistent with the D#14 prompt's instruction that hardening the no-go's characterization is itself valuable and does not require a positive result.
