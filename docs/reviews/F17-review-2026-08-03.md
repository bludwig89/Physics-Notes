## Verdict

The algebra at the centre of F17 is real, exact, and *stronger* than F17 claims — but it is not the result F17 says it is. What survives: *for the single-branch σ-bilinear $G=\psi_+^{\mathsf T}\sigma\psi_+$ (retired as the photon by F69), the transverse part is **exactly** null, $G_T\!\cdot\!G_T\equiv0$, by the Fierz identity $(\phi^{\mathsf T}\sigma\psi)\!\cdot\!(\phi^{\mathsf T}\sigma\psi)=(\phi^{\mathsf T}\psi)^2$ together with $\hat n\!\cdot\!G=\psi^{\mathsf T}\psi$; hence the mode is circularly polarised, hence **any** weighted norm $\alpha\lVert A\rVert^2+\beta\lVert C\rVert^2$ is invariant under $G_T\to e^{-i\Omega t}G_T$ for every $\alpha,\beta,\Omega$.* That is the Riemann–Silberstein null-field condition, not a Poynting-energy result — and three separate things stop it from being one:

- **The normalisation is wrong unless $c=1$.** Mohr Eq. (47) is $\Psi=(E_s,\,i\,cB_s)^{\mathsf T}$: the lower block carries $c$. The code gives $\lvert cB\rvert/\lvert E\rvert = 0.577350269190 = c_\text{lat}$ where it needs 1. So $\lVert E\rVert^2+c^2\lVert B\rVert^2$ here is a $c$-dependent multiple of the bilinear's Hermitian norm — a probability normalisation, not an energy — and "closes Gap C4" is not defensible.
- **The test has almost no failure mode.** The propagator is $\psi\to e^{-i\omega}\psi$ and the observable is a fixed multiple of $\lVert G_T\rVert^2$; the residual could not have come out non-zero except by round-off. The referee measured the same $\sim5\times10^{-14}$ at $c\in\{0,1,7.3,10^6,-3\}$ and at $\omega\in\{0,\pi/2,\pi,0.313,12.9\}$. It is blind to $c$, to $\Omega(k)$ and to the dispersion relation.
- **The object is not a rotational 3-vector.** $\lVert G_T\rVert^2 = 2(\hat n\!\cdot\!\hat y)^2$, measured to 12 digits on all 12 gate directions. The amplitude tracks the axis of the *antisymmetric* Pauli matrix and vanishes on the whole great circle $\hat n\perp\hat y$, where $E=B=0$ and the "conservation" is $0=0$.

And F17 is a photon claim about an object the code itself now forbids using as the photon.

## Which bilinear the code implements

The referee settled the blind agent's flagged blocker directly. `src/casim/engine/gauge/bilinear.py:186-195`:

```python

    """G^i = φ^T σ^i ψ.  Returns a complex 3-vector.
    Note: φ^T (transpose, not conjugate) per Paper 1 Eq. 33. ..."""
    return np.array([phi @ S @ psi for S in _PAULIS])
```
