## Verdict

The reproducible numeric core of this finding holds: every number in the finding's own tables was re-derived bit-for-bit by direct re-run of `check_stage5_circular_beam_rerun`, the declared control genuinely discriminates (verified by running `casim test --id F395-stage5-circular-beam-rerun --param beam_polarization=linear`), and target (B)'s translation-covariance test is a real, non-vacuous check (independently verified: a deliberately broken partial-translation raises the residual from `1.5×10⁻¹⁵` to `0.13`, and the exact result generalizes to y-shift, z-shift and a 2-site shift, none of which the finding itself tested). The claim must be narrowed on one point: **the off-axis correlation numbers in §2.2's table (`+0.328` at `axis=1`, `-0.101` at `axis=2`) are not converged, time-independent measurements — they are read at one arbitrarily-chosen tick count (20) that the finding does not flag as such.** An independent re-run at `ticks∈{10,20,30,40}` (all else equal) shows the `axis=1` value drifting from `0.264→0.328→0.231→0.162` — dropping *below* the gate leg's own `>0.2` threshold by tick 40 — and the `axis=2` value flipping sign (`-0.185→-0.101→-0.092→+0.100`) between tick 20 and tick 40. The qualitative claim ("circular polarization measurably changes the off-axis result versus both prior linear-type beams") is well-supported and is *robust to coupling strength* (checked `g_lat∈{0.3,0.6,1.2}`: axis=1 value stays `0.32–0.34`), so it is not a coupling-strength artifact — but presenting `+0.328`/`-0.101` as settled numbers, in a paper-style comparison table alongside F390/F391's own steady-state values, overstates their stability. A separate, independent defect: target (A)'s gate leg (`0 < charge_drift < 0.5`) is essentially non-discriminating — re-run at up to 16× the default coupling and 5× the default tick count, measured drift never exceeded `~0.10`, nowhere near the `0.5` ceiling — so while the *prose* claim ("0.54% drift, not exact") is honest and well-measured, the *registry leg* testing it offers almost no protection against a future regression.

## Independent re-derivation

Before opening the finding, module, or test (F392 and F391 were read first, as explicitly licensed by the caller as prerequisites), I reasoned through two specific risks the caller flagged:

1. **Is `Φ∘T=T∘Φ` on one translated initial state a valid, sufficient test of exact translation covariance for a coupled lattice system?** My own analysis before reading code: yes in principle, *provided* (a) the lattice has periodic boundary conditions so translation is a well-defined exact operation, (b) every dynamical state variable is translated together — including any variable tied to a lattice sublattice offset that a naive one-site shift could mismatch, and (c) no part of the per-tick update (as opposed to the initial condition) references an absolute coordinate (e.g., a driven source re-seeded at a fixed `x0` every tick, or a position-dependent absorbing boundary). A localized (non-periodic) wavepacket state is, if anything, a *stronger* test than a translation-symmetric one, since a symmetric state could pass trivially. I flagged as the key thing to verify in code: does the roll helper actually touch every array, and is the shift itself real (not an accidental no-op that would make the comparison vacuous by construction)?
2. **Could the off-axis correlation change (claim 3) be a tick-count/coupling/run-length artifact?** My own pre-read expectation: plausible, because a short (20-tick), small-lattice (L=16) coupled nonlinear run is exactly the regime where a transient, non-converged number could masquerade as a stable result, particularly if the quantity being measured (a cosine between two small, still-growing vectors) is not yet in a steady-state regime.

Both concerns were then checked directly against the code and by additional runs (not present in the finding):
- Verified `_roll_state_dict` performs a genuine, non-trivial, exactly-invertible shift on both the `(3,L,L,L)` EM-field arrays and the `(L,L,L)` fermion spinor-component arrays (raw diff after roll `≈0.997` on `E`, `≈0.459` on `f`; round-trip residual `0.0`).
- Verified the test construction is not vacuously satisfiable: deliberately breaking it (translating only `em_photon`, not `fermion_em`) raises the residual from `1.5×10⁻¹⁵` to `0.13` — eleven orders of magnitude above the `1e-9` gate bar, i.e. the metric genuinely discriminates a broken translation from a correct one.
- Extended the check the finding itself did not run: shift `(0,1,0)`, `(0,0,1)`, and `(2,0,0)` all give the same `~1.4×10⁻¹⁵` residual — target (B) generalizes beyond the one `(1,0,0)` case gated, closing what would otherwise be a real scope gap.
- Re-ran `check_stage5_circular_beam_rerun` at `ticks∈{10,20,30,40}`: found the tick-count non-robustness described in the Verdict above — this is the review's principal finding.
- Re-ran at `g_lat∈{0.3,0.6,1.2}`: off-axis values stayed essentially flat (`0.32–0.34` for axis=1), so the result is *not* a coupling-strength artifact.
- Re-ran the actual registry record: `casim test --id F395-stage5-circular-beam-rerun` → PASS; `casim test --id F395-stage5-circular-beam-rerun --param beam_polarization=linear` → correctly flips to `ok=False`, reddening exactly the one declared leg (`offaxis_correlation_changes_with_circular_beam`), matching the declared control's own stated prediction exactly.

Every number the finding reports (`0.9938…`, `-0.9490…`, `0.3284…`, `-0.1008…`, `0.005393…`, `1.5003…×10⁻¹⁵`, `0.9936…`, `2.0357…`) was reproduced bit-for-bit by direct re-run — this is the "same route, same author's code" case, which is expected for a self-review and is graded as such (not independent derivation of the underlying physics, but faithful, unassisted reproduction of the claimed numbers plus several genuinely new probes beyond what the finding itself ran).

## What would falsify this

The finding's own falsifiable content: target (B)'s `Φ∘T=T∘Φ` residual exceeding `1e-9` would falsify exact crystal-momentum covariance for this architecture (not observed here or under any of the 4 additional shift directions tried). The `m4` anomaly and off-axis-correlation claims are measurements, not predictions with a named threshold; the review's own Attack 12 shows the specific off-axis *numbers* are not stable evidence of anything beyond "circular polarization produces a genuinely nonzero, time-dependent off-axis correlation, unlike either prior linear-type beam" — a future session extending the run length or checking convergence would either confirm a steady-state value or show the correlation is still evolving at tick 20, and either outcome would sharpen (not contradict) the qualitative claim.
