complex $T_{2g}$ entry's sign only, never rotating its phase) is elementary linear algebra,
verified numerically to machine precision, and it really is sufficient to carry F254's T1/T2

skimming only the header block could take "explicitly" to mean something stronger than what is
delivered. Recommend no edit — the qualifying sentence is already present in §2 and is exactly
this review's finding.

## Independent re-derivation

Not run as a cold blind subagent (inline mode, disclosed). Self-check performed instead:

- **T1 by hand:** for $S=\mathrm{diag}(s_x,s_y,s_z)$, $(STS^\top)_{ab}=\sum_{c,d}S_{ac}T_{cd}S_{db}
  = s_a T_{ab} s_b$ (since $S$ diagonal) $=s_as_b\,t_{ab}$ for any $t_{ab}\in\mathbb C$ — this is a
  three-line algebra check, not something that needs a simulation, and it visibly does not depend
  on $t_{ab}$'s field. The finding's numerical check (200 draws, machine precision) is confirmatory,
  not load-bearing; re-derived independently here by hand and matches.
- **T5 re-run:** independently re-typed the pre-fix branch test
  `np.allclose(m_nu.imag, 0.0)` (numpy default `atol=1e-8`) against a matrix with entries
  $\sim10^{-11}$ and an injected phase of, e.g., $\pi/3$ on one entry — confirmed it returns `True`
  (real branch taken) purely because $10^{-11}<10^{-8}$ in absolute terms, regardless of the phase
  chosen. This is the review's own re-derivation of the bug's mechanism, not a re-read of the
  finding's prose, and it matches the finding's claim exactly.
- **T2 baseline by hand:** any real symmetric matrix has a real orthogonal eigendecomposition
  (standard spectral theorem), so $U$ real $\Rightarrow J=\operatorname{Im}(\text{product of reals})
  =0$ identically — re-derived independently, matches.
