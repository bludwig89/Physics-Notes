## Verdict

The finding's physics content — a genuinely `Ĉ(k)`-transverse beam does not fix F390's axis-dependent breakdown, the y-axis carries an exact `180°` `Ĉ(k)`/`k̂` anti-alignment, and the fermion's own internal spin state materially changes the recoil direction — is independently reproduced bit-for-bit against the running code (by a blind subagent that built its own, differently-coded solution, and by the referee re-running F391's actual code) and holds up under additional out-of-band perturbations the finding itself did not run. But the registry record's declared control (`tests/registry/gauge.yaml`, `F391-ck-transverse-beam-mechanism`) was found **mechanically INVALID as written**: it named a leg, `split_sourcing_couples_charge_into_EL`, that does not exist anywhere in `check_ck_transverse_beam_mechanism`'s 9-leg payload — that leg belongs to a *different* function in the same module (`check_em_photon_sourcing`, F387's entry point). Confirmed via `tools/check_control_soundness.py --run --id F391-ck-transverse-beam-mechanism` (→ `INVALID` before the fix). **Narrowed claim:** the negative/redirecting physics result stands as stated in the finding body; the registry defect (traced to a merge artifact from re-running `tools/gen_test_registry.py` after the control block was hand-written, not from anything in the finding's own prose) has been fixed in this pass and re-verified `CONTROL`. The finding's own "verified can-fail" line is therefore true again, but was briefly false at the mechanized-tooling level between authoring and this review.

## The claim, as the reviewer understands it (from the card given to subagent A)

TARGET: whether a genuinely `Ĉ(k)`-transverse (not merely `k̂`-transverse) beam-construction fix removes F390's axis/wavenumber-dependent breakdown of the photon→fermion recoil-direction correlation, and whether the fermion's fixed internal spin state is an independent contributing variable. No mechanism or answer was given in the card.

## Independent re-derivation

**Subagent A** (blind to F391's own text/code) built its own `Ĉ(k)`-transverse beam via Gram-Schmidt projection of a reference polarization onto the plane orthogonal to `Ĉ(k)` at every Fourier mode, independently reconstructed the same recipe family as `build_ck_transverse_beam_packet` without having seen it, and reproduced: exact `0°/180°/0°` axis angles (x/y/z), `L`-stable `16→128`; a beam with machine-precision transversality and zero norm loss; near-identical old-vs-new correlation numbers across a 12-point axis/`m_index` grid (differences ~`0.001–0.02`, using its own defaults, e.g. `g_lat=0.3` rather than F391's `g_lat=0.6`); and a large spin-state effect (`cos=0.517` at F391's axis=0,`m=2` config between an `f`-only and an equal-superposition initial state — matching F391's own reported number, though A used a different beam config for its own headline spin-state table). All of this matches F391's own numbers to the precision claimed, via a genuinely different code path and different defaults — the strongest form of independent support this protocol distinguishes.

**Subagent B** (the referee) re-ran F391's *actual* code directly and got bit-identical results to the committed JSON: `monopole_residual=7.622e-14`, `longitudinal_leak_fraction=0.031084`, `angle_y=180.000000°`, `angle_z=0.000000°`, `cos_onaxis=0.9926/0.9948`, `cos_m4=-0.9874/-0.9884`, `cos_offaxis=-0.00202/-0.00193`, `spin_cos=0.51671` — 9/9 PASS. It then went beyond both the finding and subagent A: rerunning the whole record under three perturbations not in the declared control (`g_lat=0.3`, `amp=0.3`, `ticks=40`) via `casim test --id F391-ck-transverse-beam-mechanism --param ...` — all three stayed 9/9 green, confirming the "breakdown persists" conclusion is not fragile to the specific default configuration. It also extended the spin-sensitivity probe to a third state (`g`-only) not tested by F391 or subagent A: at axis=1 (F391's own tested config), `f`-only and `g`-only give **nearly identical** recoil directions (`cos=0.9999996`), while at axis=0 they give **nearly exactly opposite** ones (`cos=-0.9927`) — a genuine, disclosable richness consistent with, not contradicting, F391's "spin state matters" leg.

**A discrepancy subagent A itself flagged, checked by the referee, and found not to be a problem in the finding's own text:** F391 §2's `Ĉ(k)≈R\hat k`, `R=\mathrm{diag}(1,-1,1)` reflection story, read naively, might suggest the axis=1 (y-propagation) recoil correlation should *invert* toward `-1`; the actual data shows it *collapses* toward `0` instead. The referee checked F391's own prose specifically for this and found the finding does not make that (incorrect) prediction anywhere — §2 is framed purely as "extending, not correcting, F387," and §3 treats the collapse-to-zero as an independent, separately-reported observation rather than a predicted consequence of §2's reflection formula. The tension is real and worth a future session's attention (recommendation 3 below) but is not an overclaim in the finding as written.
