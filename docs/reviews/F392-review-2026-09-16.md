## Independent re-derivation

Before reading the finding: derived from F·F = (E·E−B·B) + 2i(E·B) that nullity requires *both* |E|=|B| and E⊥B. Showed algebraically that a same-Cartesian-component construction (E and B share one axis) forces E∥B, hence Σ(E×B)=0 identically (not approximately) regardless of the field values — this needed no computation, it is forced by the construction. Derived that for ê=(e1+ie2)/√2 with e1,e2,k̂ orthonormal, ê·ê=(1−1+2i·0)/2=0, the standard optical circular-polarization null identity. Worked out, for F=f(x)·ê with **any** complex scalar f(x)=u(x)+iv(x)** (not just a monochromatic plane wave — a stronger result than the claim card required), that E=(u e1−v e2)/√2, B=(v e1+u e2)/√2 gives E·B=0, |E|²=|B|²=(u²+v²)/2, and E×B=(u²+v²)/2·(e1×e2) — all exact, pointwise, envelope-independent. Predicted cos(Σ(E×B), k̂)=1 to machine precision. Predicted the original construction's Σ(E×B)=0 exactly, by the parallel-vectors argument alone.

After reading the finding's code (`build_beam_packet` in `src/casim/engine/gauge/photon.py`): the actual implementation is component-for-component identical to the reviewer's pre-derived formulas (`E[a1]=Re(f)/√2, B[a1]=Im(f)/√2, E[a2]=-Im(f)/√2, B[a2]=Re(f)/√2`). Re-ran the derivation as a **from-scratch independent script** (not calling `check_beam_polarization_fix` or `_field_momentum_k`, using `np.cross` in real space instead of the module's k-space Parseval sum):

```

max |E.B| pointwise: 0.0
max |‖E‖-‖B‖| pointwise: 0.0
P (real-space cross): [75.12596147, 0, 0]   (finding: 75.125961)
cos(P, k_hat): 1.0                (finding: 1.000000)
```

Route: **same route** as the finding's own derivation in the sense that the underlying algebra (ê·ê=0) is essentially the unique way to null a circular-polarization RS field — there is no materially different derivation available, so this is "forced-route" independence rather than "different-route" independence per the review protocol's table. The numeric reproduction (via a completely separate script and a different summation method, real-space `np.cross` vs. k-space Parseval) is genuinely independent computation, not just independent reasoning.

## What would falsify this

A future change to `build_beam_packet`'s `"circular"` branch that reintroduces any shared Cartesian component between E and B, or a propagator change that breaks the per-mode rotation invariance of F·F=0, would move `null_condition_holds` or `equal_magnitude_holds` off machine-precision zero — exactly what the declared control demonstrates by reverting to `"linear"`.

## Recommendations
