## Verdict

F349's central, checkable claims hold up under independent re-reading of the primary sources: the citation gap is real and non-trivial (F143/F147/F149/F153 sit one cross-reference hop from F138, which F339 does cite, and even F339's own prior adversarial review missed them); every quoted number (F143's `1.33e-15`, F147's exact-zero L6, F149's `2.1e-11`, F153's `1.11e-10` and `e=0.728`) is exactly what the committed JSONs and the surrounding finding prose say; F143's "exact, non-perturbative, all orders, all scales" language for its transverse-channel result is F143's own claim, not an F349 inflation; and the OPEN grade / no-new-number framing is honestly maintained throughout, including in the one place (§8) where the finding explicitly disclaims reading intent into F339's silence.

One check is a genuine defect, not a nitpick: **check G6's "SM-content" arm is circular.** The script defines per-species charge arrays (`T3_sm`, `Y2_sm`) that are never summed; the values actually used (`sumT3sq_sm = Fraction(2,1)`, `sumY2sq_sm = Fraction(10,3)`) are hardcoded to F149's own quoted target, and — verified independently in this review — summing the arrays that *are* defined gives `1` and `46/9`, not `2` and `10/3`. So the "SM" half of "G6: independent rational recomputation" recomputes nothing; it restates F149's number and calls the restatement a check. This is the same failure mode (a check labeled "independent" that is actually a tautological reconfirmation) that F339's own 2026-08-31 review caught on its Ward-transversality check — recurring one finding later in the same lineage.

A second, milder issue: F349's "closes the same door… by an unrelated mechanism" language for avenue A, and its "narrowing" of avenue D, both lean on treating F143/F147's raw-hypercharge/vector wrap-stiffness computation (a gauge-field two-point function, pre-EWSB-mixing) as addressing the same target as F339's photon Π^μν (F251/F277, the physical paired-spinor photon, post-mixing) and F127 avenue F's proposed vertex/overlap-integral (a three-point function). These are three related but technically distinct objects. The finding and CL113 do hedge this ("closely related… not literally the F89 construction"), which keeps it from being a hard overstatement, but the hedge covers only the avenue-D/vertex case explicitly, not the avenue-A gauge-field-identity question — worth tightening.

Narrowed claim: *F349's artifact-verification (G1–G5) and its bare-charge rational recomputation are independently confirmed and accurate; its "6/6 PASS" characterization overstates G6, whose SM-content arm is circular rather than independently derived; and its "closes the same door" / "narrows" language for avenues A and D rests on treating three technically distinct gauge-sector calculations (raw hypercharge/vector wrap stiffness; physical-photon vacuum polarization; vertex overlap integral) as more nearly interchangeable than the underlying physics strictly licenses, though the finding's own hedging keeps this short of a hard overstatement for avenue D.*

## Independent re-reading of the primary sources

Read F127, F339 (and its 2026-08-31 review), F41, F143, F147, F149, F153, and CL113 in full, independently, before evaluating F349's characterization of them.

- **F127** avenue A computes a hypothetical "α_hyp" from a BZ integral (`I1 = ⟨1/(2ω)⟩ ≈ 0.446`) weighted by summed electric charges, off by a factor 115 from measurement; avenue D calls the Peierls coupling `q` structurally unconstrained. Both are loosely-specified "does *some* Sakharov-style mechanism fix the coupling" questions, not a single well-defined diagram.
- **F339** narrows avenue A using F251/F277's in-model, one-loop, symbolic verification that the *physical (paired-spinor) photon's* Π^μν is transverse — note F251 is itself flagged `SUPERSEDED (S12-F277-refold-removed-qed-and-gluon)` in `findings-index.md`; F339 correctly cites F277 as the corrected version and F349 does not disturb this. F339 narrows avenue D using F165/F279's rank-6-of-7 hypercharge-ratio system. F339's own review (`docs/reviews/F339-review-2026-08-31.md`) already caught one "independent re-derivation" claim (the Ward-transversality check) as actually re-verifying a model-independent tensor tautology rather than F251/F277's harder result — a directly analogous failure mode to the one this review finds in F349's G6.
- **F41** establishes that hypercharge rides on the same `U(x)` field as SU(2)_L via a Stueckelberg extension, with no separate scalar; this is a fair (if compressed) basis for F349's "no bare kinetic term" gloss, though F41's own text never uses that phrase — it is a reasonable paraphrase, not a quote-mismatch.
- **F143** (2026-06-12): the *transverse* channel of the induced U(1)_Y wrap stiffness is exactly zero, by a unitary-conjugation argument, for **any** static gauge field — F143's own §2 text says "not merely at tree level: at all loop orders, at every scale," matching F349's "exact, non-perturbative, all orders, all scales" verbatim in substance. This is not an F349 overstatement; it is what F143 itself claims. F143's own §7 "Honest scope" correctly restricts the *longitudinal* channel's stronger claims (no such "all orders" language there) — F349 quotes only the transverse (§2) result with the strong language, correctly.
- **F147** (2026-06-12): one-tick sea rigidity, zero induced stiffness in **both** vector and staggered (hypercharge) channels, exact to the numerical floor (`<1e-12`), verified in the committed JSON as literally `-0.0e+00` in both channels. F349's "<1e-11" is a looser (safe) bound than the true `<1e-12`, not an inflation.
- **F149**: one-tick rigidity survives turning on a Dirac mass proxy (`m=0.4`), residual `-2.1e-11` in both channels — matches F349's quote exactly, verified against the JSON.
- **F153**: the diamagnetic Peierls contact is charge-blind (`1.11e-10` in the JSON, matching F349's quote to the digit); the physical `E_g` condensate coupling at the lepton point is `e = 0.7279` (rounds to `0.728`, matching F349's quote), explicitly flagged by F153 itself as `O(1)`, outside any small-`m` perturbative proxy's validity.

All five numeric quotes F349 makes from F143/F147/F149/F153 check out exactly against the committed JSON artifacts and against the surrounding finding prose, not just isolated JSON keys — this review read the prose, not only the numbers.

The one substantive independent finding of this review is the **G6 circularity** described above and in the Attacks table (line references: `tests/findings/test_F349_alpha_em_convergent_stiffness_evidence.py:153-164`).
