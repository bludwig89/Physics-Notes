# CL021 — The cosmological constant is not derived — the 121-order problem is reduced to the Omega_Lambda coincidence

## Statement

The cosmological constant is **not derived**. F193/F196 reduce the classic 121-order problem to the $\Omega_\Lambda\approx0.69$ coincidence, **which is not the same as explaining it**.

## What it extends

Recorded so that **absence is not read as a prediction**. This is a scope boundary, not a result: the project does not assert it, and `status: not_claimed` is the assertion that it does not assert it. The reduction is a real result — F164 quantified the 120.8-order overshoot, F193 showed the ontic vacuum gravitates as exactly zero, and F196 derived the dilution exponent $p=2$ — but the residual is a coincidence, not a derivation, and the card refuses the stronger reading.

## Falsifier

None on the non-claim. The **component** results (F193's exact zero, F196's $p=2$) are live supporting claims carried by their backfill cards and are falsifiable individually.
