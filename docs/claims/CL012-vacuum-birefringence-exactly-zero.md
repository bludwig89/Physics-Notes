# CL012 — The physical photon is exactly non-birefringent — structurally, not within a tolerance

## Statement

The physical (paired) photon is **exactly** non-birefringent — not within a tolerance, but structurally: the pair carries one single-valued rotation rate $\Omega_\text{pair}$, so **there is no second branch to split from**.

## What it extends

Lorentz-violating quantum-gravity phenomenology, in which a discrete vacuum generically produces helicity-dependent propagation. The model's discreteness does **not** produce it, and the reason is structural rather than a cancellation.

## Falsifier

**A confirmed first-order vacuum birefringence in GRB or AGN polarimetry contradicts it** — and would, conversely, **revive the excluded chiral construction**. This is the sharpest falsifier in the register: there is no tolerance parameter, so any confirmed non-zero effect is fatal to the paired-photon identification (CL002) rather than merely constraining it.
