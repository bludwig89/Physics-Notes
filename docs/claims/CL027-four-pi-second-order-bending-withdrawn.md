# CL027 — WITHDRAWN — the 4*pi second-order light-bending coefficient

## Statement

**RETRACTED.** The second-order light-deflection coefficient was predicted as $4\pi$, against GR's $15\pi/4$. **The model no longer predicts it**; with the Schwarzschild vacuum solution the coefficient is GR's.

## What it extends

It asserted a measurable second-order departure from GR's deflection law. It no longer does.

## Evidence

| Source | What it shows | Exactness |
|---|---|---|
| `findings/F111-second-order-light-deflection.md` | The $4\pi$ coefficient, as originally derived from the exponential metric | exact |
| `findings/F178-gravity-full-tensor-adoption.md` | The supersession: exponential form is PPN-order only, so the second-order term is not the model's | — |

## Falsifier

**Inverted.** A second-order deflection measurement matching GR's $15\pi/4$ would previously have falsified the model. **It does not.**

## Status & history

**Withdrawn 2026-08-02** (summary revision 2), superseded by F178. The card is kept because **this was published as a live claim between 2026-06-08 and 2026-08-02**, and a withdrawn claim that is deleted is a claim that gets re-made. This is the cleanest of the five withdrawals: the coefficient is an exact consequence of a metric the model no longer holds to be exact. F111's algebra is correct and its premise is not.
