# CL013 — c_grav = c_gamma exactly, with no free coefficient

## Statement

$c_\text{grav}=c_\gamma$ **exactly**, with no free coefficient. GW170817 gives residual $\le3\times10^{-83}$.

## What it extends

Modified-gravity phenomenology, where $c_\text{grav}/c_\gamma-1$ is a tunable parameter that GW170817 constrains to $\sim10^{-15}$. Here it is not tunable at all: the equality is inherited through the F79 zero-tree-stiffness channel.

## Falsifier

**Any confirmed non-zero $c_\text{grav}/c_\gamma-1$ falsifies the inheritance mechanism.** There is no free coefficient to absorb it — unlike a modified-gravity model, the claim cannot be re-fitted to a non-zero measurement, only abandoned.
