==============================================================================================
DEFECT 2 -- bcc_curl_symbol is not the symbol of a curl
==============================================================================================

2a.  Direction.  A curl's symbol points along k.  This one does not.
       cos(C, k)       min -1.000000000   max 1.000000000
       modes with cos(C,k) < 0.99 :  3864 of 4088
     The k->0 limit is C ~ R.k with R = diag(1,-1,1), inherited from
     bcc_spin_axis's y-sign flip (the Bisio walk's chirality convention).
     That reflection reproduces all three angles F387 measured:
       angle(R.k, k) on cubic axis (1,0,0)   = 0.000000 deg
       angle(R.k, k) on face diag (1,1,0)    = 90.000000 deg
       angle(R.k, k) on body diag (1,1,1)    = 70.528779 deg

2b.  THE DEFINING IDENTITY OF A CURL:  curl(grad phi) = 0, i.e. C x G = 0.
       |C x G| / (|C||G|)  with spectral   G = k           :  max 1.000000   mean 0.741692
       |C x G| / (|C||G|)  with fwd-diff   G_j = e^{ik_j}-1 :  max 1.000000   mean 0.707173
       control, a TRUE curl symbol C = k                         :  max 0.000e+00

     The identity the codebase cites as its sanity check, C.(C x x) == 0, is
     VACUOUS -- it holds for every vector field whatsoever, so it carries no
     information about whether C is a curl.  The no-monopole gate i.Chat.B = 0
     tests exactly that vacuous identity.  The one that fails was never tested.
